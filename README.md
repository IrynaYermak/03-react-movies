🎬 React Movies — Movie Search and Information App

Live Demo: https://03-react-movies-six-neon.vercel.app/

React Movies is a simple and intuitive web application that allows users to search for movies and view detailed information such as ratings, descriptions, genres, and release dates. The project demonstrates clean component structure, API integration, modern React features, and responsive UI design.
